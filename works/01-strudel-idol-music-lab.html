互動網頁 × Live Coding｜偶像風格音樂實驗室

選一位歌手的風格，用滑桿與開關即時生成一段原創循環音樂。

作品連結 ↗ GitHub 原始碼 ↗

作品概述

使用者選一位歌手的「風格模組」，拖拉滑桿、開關音軌，就能即時聽到「如果用這位歌手的風格做一首歌，會是什麼聲音」。所有音樂都由 Strudel 在瀏覽器裡即時生成，是依風格要素重新編寫的原創循環，不使用任何原曲音檔或旋律。

動機

這份作業要做一個互動網頁，我選了偶像當主題。目標使用者是偶像粉絲，以及對音樂製作好奇、但不懂樂理的人。我希望使用者不只聽到「像」，還能知道為什麼聽起來像——是速度、鼓的型態，還是和弦走向。

使用技術

技術 在這個作品的用途
Strudel 瀏覽器中的 live coding 音樂環境，透過 @strudel/web 產生並播放所有音樂
Mini-notation 用短字串描述節奏，例如 "bd ~ sd ~" 代表大鼓、休止、小鼓、休止
Web Audio API 即時合成鋸齒波、方波、三角波等音色，處理濾波與殘響
Dirt-Samples TidalCycles 社群的開源鼓組音色庫
YouTube IFrame Player API 嵌入參考歌曲，和生成音樂互相自動暫停
HTML／CSS／JavaScript 依作業規定，全部寫在單一 index.html
GitHub Pages 部署靜態網頁，push 後自動更新

運作方式

  1. 每位歌手是一個「風格模組」，記錄 BPM、鼓組型態、和弦進行、音色等要素。
  2. 使用者選模組、拉滑桿或開關音軌時，程式更新狀態物件。
  3. buildCode() 依模組與參數組出一段新的 Strudel 程式碼。
  4. Strudel 解析這段程式碼，在不中斷節拍的情況下換上新的聲音。
  5. 同步更新風格說明卡與程式碼面板；使用者也可以直接改程式碼後執行。
  6. 「對照原曲」可以用 A／B 切換，比較生成版本和參考歌曲。

設計重點

  • 7 個風格模組：每位歌手挑 3 首代表歌曲，整理 BPM、調性、鼓組與音色，再寫成模組參數；新增歌手只要在 MODULES 陣列多加一個物件。
  • 只借風格、不抄原曲：只借用 BPM、調性、鼓組型態、和弦進行類型等曲風共通要素，不使用原曲音檔、旋律或歌詞。
  • 把 live coding 包裝成一般人能用的介面：使用者不用懂程式，操作滑桿就是在背後改寫 Strudel 程式碼；想體驗真正的 live coding，也能在程式碼面板直接修改。
  • 載入失敗不卡住：unpkg 連不上時改用 jsdelivr；鼓組音色載入失敗時只用合成器播放，並在畫面上顯示原因。
  • 低飽和視覺：深灰底加銀色金屬點綴，選中模組時背景淡淡染上該歌手的代表色。

範例

一段有鼓、貝斯和和弦的 Strudel 循環。把 .lpf(800) 的數字改大或改小，聲音會立刻變亮或變悶：

stack(
  s("bd*4, [~ sd]*2, hh*8"),          // 大鼓、小鼓、hi-hat
  note("<c3 a2 f2 g2>").s("sawtooth")  // 貝斯走和弦根音
    .lpf(800),                         // 濾波器
  note("<[c4,e4,g4] [a3,c4,e4] [f3,a3,c4] [g3,b3,d4]>").s("triangle")
)
