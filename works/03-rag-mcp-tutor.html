RAG｜MCP 課程助教

把 Anthropic 的 MCP 課程做成知識庫，打造只根據課程內容回答的中文助教。

作品概述

「MCP 助教」是一個 RAG（Retrieval-Augmented Generation，檢索增強生成）對話機器人。知識來源是 Anthropic Academy 的〈Introduction to Model Context Protocol〉課程。使用者用中文發問後，助教會先從課程知識庫找出相關段落，再根據這些段落回答，並標註答案出自哪份文件。

動機

最近我在 Anthropic 的課程網站上學習 MCP。MCP 對我來說是全新的概念，課程又是全英文，遇到問題常常要回頭翻好幾個單元。我希望有一位隨時可以發問的助教，能用中文回答各種問題，而且答案要以課程內容為準、不能亂編，所以把整門課程的內容做成 RAG 知識庫。

使用技術

技術 在這個作品的用途
知識庫資料集 課程 11 個單元的中文教學摘要，加 1 份中英名詞對照表，共 12 份文件
Embeddings 把文件切塊後轉成向量，用來比對問題與段落的相似度
FAISS 儲存向量並快速檢索最相關的段落，匯出成 vector_db.zip
Colab 建立與載入知識庫、執行問答；從 Google Drive 自動讀入知識庫
System Prompt 「MCP 助教」人設與 13 條回答、教學、限制規則

運作方式

  1. 整理資料：依老師示範資料集的格式，把課程內容改寫成 12 份繁體中文文件，附 sources.csv 與 問題集.csv。
  2. 建立知識庫：將文件切塊、計算 embeddings，存進 FAISS 向量資料庫並匯出。
  3. 載入知識庫：從 Google Drive 自動讀取 vector_db.zip，不需要每次手動上傳。
  4. 檢索與回答：使用者提問後，先找出最相關的段落，再連同 system prompt 交給語言模型，產生附引用編號的回答。

設計重點

  • 中文改寫、術語保留英文：方便用中文提問與檢索，同時讓 tool、resource 等名詞能和程式碼對得上。
  • 程式碼保留課程原始範例：助教可以逐段解釋實際的程式，而不是自己編寫。
  • 名詞對照表：額外整理一份中英術語表，讓中文問題也能檢索到英文概念。
  • 知識庫外的問題要說不知道：問題集中有 3 題是課程沒教的內容（例如「怎麼用 TypeScript 寫 MCP Server？」），用來測試助教會不會回答「目前教材沒有足夠資訊」。
  • 助教而不是代寫工具：system prompt 規定針對初學者先用白話解釋，遇到測驗題改用引導提問，不直接給答案。

範例

問題集.csv 中的測試問題：

測試問題 預期行為
MCP 跟一般的 tool use 有什麼差別？ 引用「MCP 是什麼」文件回答
我想讓使用者按一個按鈕就執行固定流程，應該用 Tools、Resources 還是 Prompts？ 引用「三大原語比較」文件，說明應使用 Prompts
怎麼用 TypeScript 寫 MCP Server？ 課程只教 Python，應回答目前教材沒有足夠資訊

延伸方向

  • 比較 top-k = 1 與 3 的檢索結果，以及純 LLM 與 RAG 的回答差異。
  • 課程影片內容目前沒有收錄，之後可以補上影片重點，讓知識庫更完整。
  • 知識庫是中文摘要、程式碼是英文，可以觀察中英混合內容對檢索的影響。
